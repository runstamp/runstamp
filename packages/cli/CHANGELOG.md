# @runstamp/cli Changelog

## 1.0.0

- Uses the descriptor-only `@runstamp/catalog` for operation discovery.
- Retains all four document engines for deterministic local rendering.

## 0.1.0

- Initial `runstamp` binary for rendering `pdf`, `docx`, `xlsx`, and `pptx` JSON specs.
- Supports `--in`, `--out`, `--validate`, `--strict`, and `--no-strict`.
