# Runstamp conformance matrix

Generated by `node scripts/generate-conformance-matrix.mjs` from the output of
`pnpm contract:verify`. Do not edit by hand.

Every cell is the result of running the gate against the package's **built**
artifact — what a consumer installs — not against its sources.

- Contract version: `1.0.0`
- Packages verified: 12

`warn` marks a gate that is passing but should not be relied on yet; the reason
is listed under [Known gaps](#known-gaps). It is reported rather than hidden
because a formality that always passes is worse than no gate at all.
